# Kryptografia

## Punkty można otrzymać na dwa sposoby:
- prezentowanie zadań przy tablicy
- nieobecności nieusprawiedliwione (max. 3 nieobecności, za drugą i trzecią -2 punkty)

## Progi ocen

- dost - $3$ punkty
- db - $3 + 2w$ punktów
- db+zw - $3 + 3w$ punktów
- bdb+zw - $3 + 5w$ punktów

Gdzie $w = \frac{18}{N}$, a $N$ to liczba studentów w grupie.
